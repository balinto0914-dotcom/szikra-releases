# Szikra — Windows telepítők

A DeepMorrow **Szikra** Windows-alkalmazásának telepítői. A letöltés és a leírás: https://www.deepdays.eu/szikra

| Verzió | Fájl | SHA-256 |
| --- | --- | --- |
| 5.4.0 | `v5.4.0/Szikra-Setup.exe` | `785a62c5f7673b3b7c1aa9ffeb213a78d9ee42362c7a2f1fb21ce3b9fa510649` |

A telepítő még nincs kereskedelmi tanúsítvánnyal aláírva, ezért a Windows SmartScreen figyelmeztethet. Ellenőrzés PowerShellben:
`Get-FileHash .\Szikra-Setup.exe`

A használathoz DeepMorrow-fiók kell (ingyenes csomaggal is működik).
